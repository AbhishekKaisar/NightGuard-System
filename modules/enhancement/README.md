# Low-Light Enhancement Module

## Description
Preprocessing pipeline to enhance low-light CCTV frames before passing them to detection modules.

## Expected Approach
- Contrast/brightness adjustment (alpha-beta correction)
- CLAHE (Contrast Limited Adaptive Histogram Equalization)
- Gamma correction
- Noise reduction (Gaussian blur)
